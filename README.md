# 정보처리산업기사(과정평가형) 실기 참고자료

Eclipse · Tomcat · Oracle로 실기 환경을 구성하고, JSP로 일정 관리 프로그램(시작화면 · 일정등록 · 회원현황 · 일정현황)을 만드는 과정을 단계별로 정리한 학습 페이지입니다.

## 보는 방법

- `index.html`을 브라우저로 열면 됩니다. 캡처 이미지는 `images/` 폴더에 있어야 함께 보입니다.
- GitHub Pages를 켜면(Settings → Pages → Branch: main / root) 웹 주소로도 볼 수 있습니다.

## 구성

| 챕터 | 내용 |
|---|---|
| 공식 자료 | 한국산업인력공단 [25V5] 시험 구성과 예시 과제 요약 |
| 1 | 개발 환경 구성 (Workspace, UTF-8, Tomcat, Oracle 드라이버, Util.java) |
| 2 | 데이터베이스 입력 (db.sql) |
| 3 | 화면 개발 (index.jsp, style.css, list.jsp, list_j.jsp, reg.jsp, action.jsp) |
| 4 | 코드 주석 해설 |

공식 문제지의 저작권은 한국산업인력공단에 있으며, 이 페이지는 학습용으로 요약·재구성한 것입니다.
